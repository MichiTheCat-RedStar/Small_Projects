BreanFun создан по подобию Brainfuck, однако со своими элементами
Нынешнюю версию можно посмотреть в файле "Changelog.txt"

Телеграм: https://t.me/RedStarEngineers
Резерв: https://t.me/TeaTechnology


Подробнее о версиях:
"BrainFun" - стандартная версия (version 1.0)
"BrainFun+" - версия с большим количеством функций
"BrainFunLite" - лёгкая версия без лишних настроек

"ReASCII" - перемоздаёт "ASCII.txt" при его повреждении



Ниже описаны значения символов:

">" - перемещает выбор ячейки правее
"<" - перемещает выбор ячейки левее
"+" - добавляет ячейке единицу
"-" - убирает ячейке единицу
"." - выводит значение ячейки
"," - задаёт значение ячкйке пользователем
"$" - копирует значение ячейки в стак
"#" - вставляет значение стака в ячейку
"r" - задаёт случайнок значение ячейке
"*" - суммирует значение ячейки со значением стака
"%" - вычитает значение ячейки от значения стака
"«" - перемещает выбор ячейки на первую ячейку
"»" - перемещает выбор ячейки на последнюю ячейку
":" - выводит значение как символ ASCII
";" - задаёт значение ячейке буквой ASCII от пользователя
"{" - если значение в ячейке больше нуля, то шагает левее
"}" - если значение в ячейке больше нуля, то шагает правее
"C" - отчищает все ячейки памяти
"c" - отчищает выбранную ячейку памяти
"|" - останавливает компилирование, если значение ячейки равно нулю
"(" - позволяет задать значение числом
")" - закрывает считывание значения
"[" - если значение ячейки больше нуля, то сохраняет шаг кода
"]" - если значение ячейки больше нуля, то загружает шаг кода
"^" - перемещает выбор ячейки на заданное в ячейке памяти значение
"_" - убирает ячейке единицу и если значение минимальное, то оставляет его
"=" - добавляет ячейке единицу и если значение максимальное, то оставляет его
"~" - если значение ячейки равно значению стака, то перемещает выбор правее
"❛" - добавляет единицу в стак
"❜" - убирает единицу из стака
"@" - исполняет шаг кода заданный в стаке
"'" - комментирует код внутри символов
"!" - если значение ячейки больше нуля, то делает его равным нулю иначе она и так равна нулю (чем отличается от "c"?)
"?" - если значение ячейки больше нуля, то перемещает выбор правее, иначе левее
"/" - если значение ячейки больше нуля, то сохраняет шаг кода, в ином случае комментирует до "]"
"№" - ждёт 0.5 секунд


Символы BrainFun+:

"o" - вывести [Out]
"O" - отчищает [Out]



Принцип работы:

1. Основы:
    1. Есть список с 32-мя ячейками памяти
    2. В каждой ячейке может хранится число от 0 до 255
    3. Между ячейками можно переключаться с помощью команд "<" и ">"
    4. В саму ячейку можно задать данные с помощью команд "+" и "-", которые добавляют\убирают одно значение соответственно
    5. Значение можно выыести с помощью "."
    6. Значения не могут быть отрицательными

2. ASCII:
    1. Так же можно вывести значение с помощью таблицы ASCII ("ASCII.txt"), для этого используется команда ":"
    2. Так же пользователь может сам задать значение в виде символа ASCII с помощью ";"
    3. Таблицу ASCII можно перезаписать, если она была повреждена с помощью "ReASCII.py"

3. Ввод:
    1. Пользователь может вводить данные в ячейку сам, с помощью  "," (или ";" если требуется ввести символ ASCII)
    2. Есть более удобный способ заполнения данных, если нет нужды в сложениях и вычитании - "(" и ")"

4. Циклы:
    1. В BrainFun нет полноценных циклов, но их можно создать с помощью условий
    "[" - сохраняет порядковый номер символа кода, который сейчас исполняется, если значение ячейки больше нуля
    "]" - загружает этот порядковый номер и воспроизводит код с этой части, если значение ячейки больше нуля
    Следовательно можно сделать на этом цикл, давайте попробуем создать код, который будет умножать число на два:
    ,[->++<]>. - вот и готов код, давайте расмотрим его подробнее:
        "," - пользователь задаёт значение в первую ячейку
        "[" - запоминается какая часть кода исполняется, если пользователь ввёл значение больше нуля
        "-" - отнимается единица от данной ячейки памяти
        ">" - переходим на вторую ячейку памяти
        "++" - прибовляем к ней два значения
        "<" - возвращается к первой ячейке
        "]" - вновь проходится по коду начиная с "["
        После того, как в ячейке памяти будет 0, то есть цикл пройдёт столько раз, сколько задал пользователь, то код пропустет "[" и "]" и перейдёт дальше
        ">" - код переключится на следующую ячейку памяти, в данном случае на вторую
        "." - выведется число, то есть значение в два раза больше, чем то, что ввёл пользователь
        (Поправка из версии 1.7) Так как "[" не является циклом, то код исполняется далее при вводе 0 от чего все каоманды проходят вновь и тратят много шагов.. В качестве исправления была добавлена команла "/", которую я советую использовать здесь вместо "["
    2. Стоит подметить, что так как в BrainFun нет полноценных циклов, то, в отличие от Brainfuck, вы не сможете вставить цикл в цикл

5. Стак:
    1. Стак - это неограниченное значением ячейки памяти число, которое находится вне списка
    2. Стак очень удобно использовать для переноса данных с одного места на другое (Привер кода: " «,^$«,^# ")
    3. В стак можно добавить число с помощью "$"
    4. "#" - позволяет вставить значение из стака в ячейку, но при этом значение в стаке стирается

6. Поправки:
    Здесь расказанна основная информация, чтобы новичках было проще, поэтому не стоит говорить о том, что здесь можно было написать более удобные способы, вместо этого я напишу тут парочку из них:
    Использование "(" и ")" вместо "+" с "[" и "]" (намёк на то, что вместо задачи числа циклом для сокращения места, как в Brainfuck - в BrainFun можно использовать сразу круглые скобочки)
    Использование "c" вместо "(0)$>#" или цикла из "_"

7. Особенности:
    BrainFun старается быть понятным пользователю, поэтому у него есть несколько особенностей:
    1. Если значение ячейки меньше нуля, то оно станет максимальным (255 по стандарту) (Так же это работает и в сторону максимального значения)
    2. Если выбор ячейки выходит за рамки, то переходит первой или последней («<'Выберет ту же ячейку, что и выбрала бы команда "»"')
    3. Значения стака не зависит от максимального значения ячеек (Может быть более стандартных 255)
    4. В BrainFun+ вы можете прожимать [Enter] и значения по умолчанию, а так же [N] будут выбираться автоматически
