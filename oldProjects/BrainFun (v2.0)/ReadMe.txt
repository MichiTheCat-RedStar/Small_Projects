BreanFun создан по подобию Brainfuck, однако со своими элементами
Нынешнюю версию можно посмотреть в файле "Changelog.txt"

Телеграм: https://t.me/RedStarEngineers
Резерв: https://t.me/TeaTechnology


Подробнее о файлах:
"BrainFun.py" - обычная версия, куда достаточно вставить код
"BrainFunPlus.py" - версия с большим количеством настроек и функций
"Changelog.txt" - информация об обновления
"Help.txt" - информация об основах написания кода на BrainFun и смежные с этим темы
"ReadMe.txt" - важная информация (вы здесь)
"Save.txt" - файл сохранения кода

Файлы в "Others":
"ReASCII.py" - пересоздаёт "ASCII.txt" и "ASCII+.txt"
"ASCII.txt" - таблица ASCII
"ASCII+.txt" - расширенная таблица ASCII
"Experiments.txt" - эксперементы разраотчика с кодом

- Файлы в OldVersion соответствуют версии написанной в скобках


Символы BrainFun:

">" - перемещение к ячейке правее
"<" - перемещение к ячейке левее
"+" - добавление одного числа к ячейке
"-" - вычитание одноко числа из ячейки
"$" - записывание число из ячейки в глобальную переменную
"#" - вставляет число в ячейку из глобальной переменной, обнуляя её
"." - выводит значение ячейки в виде числа
"," - задаёт значение ячейке в виде числа
":" - выводит значение ячейки в виде символа ASCII
";" - задаёт значение ячейке в виде числа из символа ASCII
"r" - задаёт ячейке случайное значение от нуля до одного
"R" - задаёт ячейке случайное значение от нуля до максимально возможного
"s" - ждёт 0.25 секунд перед выполнением следующего символа
"«" - перемещение к первой ячейке
"»" - перемещение к последней ячейке
"c" - делает ячейку равной нулю
"|" - останавливает выполнение кода, если значение ячейки равно нулю
"↓" - перезагрузить компьютер, если ячейка равна нулю
"{" - перемещение к ячейке левее, если значение больше нуля
"}" - перемещение к ячейке правее, если значение больше нуля
"[" - добавляет номер выполняемого символа в конец списка кода, если значение ячейки больше нуля
"]" - вставляет номер выполняемого символа в код с конца списка кодов и удаляя его из списка, ксли значение ячейки больше нуля
"'" - пропускает символы внутри себя
